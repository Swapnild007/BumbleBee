# Space Telecom UI Concept

A mobile-first recreation of the supplied Sogaso telecom-app reference. The reference image is the source of truth for the visual language: near-black space backdrop, Earth horizon, oversized data typography, translucent glass panels, restrained cyan lighting, compact metrics, and bottom navigation.

## Implementation

- Single-file UI in `index.html` with embedded CSS and JavaScript.
- Responsive mobile-first layout with a space/Earth-inspired visual backdrop.
- Home, Usage, Rewards, and Profile navigation.
- Interactive plan details, notification toast, usage-period selector, and referral action.
- Web app manifest and service worker for an installable shell.

## Data and scope

All usage values are illustrative reference values. This project is a front-end UI concept and is not connected to a carrier, account, billing system, or live telemetry.

## Run locally

Serve this folder over HTTP, or deploy it with GitHub Pages. The interface uses no build step and no third-party JavaScript dependencies.

## Visual acceptance criteria

- No previous assistant interface, orb, or character branding.
- No purple/lavender theme or gold assistant theme.
- Reference-led dark space composition, cyan accents, glass-like cards, oversized numeric hierarchy, and compact bottom navigation.
- All controls visible in the interface should respond meaningfully.
